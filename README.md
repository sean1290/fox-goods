# 폭스패밀리 굿즈샵 (후드티 · 맨투맨 주문)

Fox Learning Center 학생·학부모용 주문 페이지와 관리 페이지입니다.
감정체크 앱과 같은 방식(정적 HTML + Google Apps Script + Google Sheet)으로 동작합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 주문 페이지 (상품 사진, 사이즈표, 주문서, 입금 안내) |
| `admin.html` | 관리 페이지 (주문 목록, 입금 확인, 도착 문자 보내기, 마플 주문용 사이즈 집계) |
| `shop.gs` | Apps Script 백엔드 (주문 저장, 문자 발송) |
| `images/` | 상품 사진 넣는 곳 |

이 폴더는 따로 떨어져서 동작하니, 폴더째로 별도 사이트로 올리면 됩니다 (아래 5단계).

## 1. Google Sheet + Apps Script

1. 새 Google Sheet 만들기 (예: "Fox 굿즈 주문")
2. `확장 프로그램 → Apps Script` → `shop.gs` 내용 전체 붙여넣기
3. 맨 위 `SHOP` 설정 고치기: **계좌(은행/계좌번호/예금주)**, 예상 도착 시기, 수령 방법
4. `프로젝트 설정(⚙️) → 스크립트 속성`에 추가:
   - `ADMIN_PASSWORD` — 관리 페이지 비밀번호
5. `배포 → 새 배포 → 웹 앱`, 실행 계정: **나**, 액세스: **모든 사용자** → URL 복사

> `shop.gs`를 고친 뒤에는 `배포 → 배포 관리 → 수정(연필) → 새 버전`으로 다시 배포해야 반영됩니다.

## 2. 페이지에 URL 연결

`index.html`과 `admin.html`의 `const SCRIPT_URL = '';` 에 복사한 URL을 넣습니다.

## 3. 상품 정보 넣기 (`index.html` 의 `PRODUCTS`)

- **사진**: 마플에서 받은 목업 이미지를 `images/`에 넣고 파일 이름을 맞춰 주세요
  (`hoodie-front.jpg`, `hoodie-back.jpg`, `sweatshirt-front.jpg`, `sweatshirt-back.jpg`).
  사진이 없으면 회색 옷 그림이 대신 나옵니다.
- **가격 / 사이즈**: 실제 판매가와 마플에서 고른 상품의 사이즈로 바꿔 주세요.
- **사이즈표**: ⚠️ 지금 들어 있는 숫자는 **예시**입니다. 마플 상품 페이지의 실측 사이즈표 값으로 꼭 바꿔 주세요.
- 상품을 더 추가하려면 `{ ... }` 블록을 하나 복사해서 `id`만 다르게 하면 됩니다.

## 4. 자동 문자 (SOLAPI)

주문하면 바로 "주문 접수 문자"(상품·사이즈·금액·입금 계좌·예상 도착)가 가고,
관리 페이지에서 버튼을 누르면 "도착 문자"가 갑니다. 문자는 [SOLAPI](https://solapi.com)로 보냅니다.

1. SOLAPI 가입 → 충전 (장문 문자 1건에 약 30~50원)
2. **발신번호 등록** (내 휴대폰 번호, 본인인증) — 법적으로 필요
3. API Key 발급
4. Apps Script 스크립트 속성에 추가:
   - `SOLAPI_API_KEY`
   - `SOLAPI_API_SECRET`
   - `SENDER_PHONE` — 등록한 발신번호 (예: 01012345678)
5. Apps Script 편집기에서 `testSms` 함수 실행 → 내 휴대폰으로 테스트 문자가 오면 완료
   (처음 실행 시 외부 요청 권한을 허용해야 합니다. 그 다음 웹 앱도 새 버전으로 다시 배포)

설정 전에도 주문은 정상으로 받습니다. 관리 페이지의 "도착 문자 보내기"를 누르면
문자 내용이 채워진 휴대폰 문자 앱이 열리고, 보낸 뒤 "보냄으로 표시"를 누르면 됩니다.

## 5. 올리기

이 `fox-shop` 폴더를 [Netlify Drop](https://app.netlify.com/drop)에 끌어다 놓으면 주소가 생깁니다.
- 주문 페이지: `https://<주소>/`
- 관리 페이지: `https://<주소>/admin.html` (비밀번호 필요, 링크는 공유하지 마세요)

## 운영 흐름

1. 학부모/학생이 주문 → 주문 접수 문자 자동 발송 → 계좌로 입금
2. 관리 페이지에서 통장 입금 내역을 보고 **입금 확인** 클릭
3. 주문 마감 후 **마플 주문용 집계**(상품별·사이즈별 수량)를 보고 마플에 한 번에 주문
4. 상품이 도착하면 **도착 문자 보내기** (한 건씩 또는 "한꺼번에 보내기")
5. 주문 마감은 `shop.gs`의 `open: false` 로 (다시 배포)

## 참고

- 주문 내역은 Google Sheet의 「주문」 탭에 그대로 쌓입니다. 시트에서 직접 확인·수정해도 됩니다.
- 연락처는 개인정보이니, 상품 전달이 끝나면 시트에서 지워 주세요 (주문서에 그렇게 안내되어 있습니다).
- 결제 금액은 페이지에서 계산해 보냅니다. 입금 확인할 때 금액이 맞는지 한 번 봐 주세요.
